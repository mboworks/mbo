      71                 :             : // due to C++20 limitations. The latter takes a literal string.
      72                 :             : //
      73                 :             : // If instantiated, the size of the generated types is 1 (c++ minimum size).
      74                 :             : // The types do not have non-static member fields.

      83                 :             : // Instances can be compared against anything that can be compared against a
