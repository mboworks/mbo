      44              : // Template class `Required<T>` is a wrapper around a type `T`. The value can be
      45              : // replaced without using assign or move-assign operators. Instead the wrapper
      46              : // will call the destructor and then in-place construct the wrapped value using
      47              : // the type's move constructor.
      48              : //
      49              : // In other words the reason for this type is the rare case where a variable of
      50              : // a type `T` needs to be assigned (say for a test) while the type follows the
      51              : // rule of 0/3/5 but only allows move-construction.
      52              : //
      53              : // The type is similar to `RefWrap` and `std::optional` (only it cannot be
      54              : // `std::nullopt`).
      55              : //
      56              : // The wrapper is not implemented itself as a wrapper or specialization of STL
      57              : // type `std::optional` due to its overhead.
      58              : //
      59              : // `emplace` constructs its replacement before destroying the current value.
      60              : // Since `Required` has no empty state, replacement is available only when `T`
      61              : // can then be moved into place without throwing.
      62              : //
