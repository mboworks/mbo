      35                 :             : // Type `AnyScan` is similar to `std::span`, `std::range` and `absl::Span`. However it works with
      36                 :             : // any container that supports `begin()`, `end()` and whose `iterator` (likely the `const_iterator`)
      37                 :             : // is a `std::input_iterator`. Type `ConstScan` is similar to `absl::Span<const T>` made from
      38                 :             : // `absl::MakeConstSpan`. And while `AnyScan` and `ConstScan` return by reference, `ConvertingScan`
      39                 :             : // returns by copy which allows it to convert the values of the container to the specified value.
      40                 :             : //
      41                 :             : // The Scan types supports pretty much all STL containers including `std::initializer_list`. Beyond
      42                 :             : // `begin()` and `end()` the containers must be supported by `std::empty(C)` and `std::size(C)` as
      43                 :             : // they provide `begin()` and `end()` calls. Those are only executed when actually called, so if
      44                 :             : // they are costly, then that cost only applies if needed.
      45                 :             : //
      46                 :             : // IMPORTANT: This type is INDEPENDENT of the container type that means it is possible to write
      47                 :             : // single functions that can take containers of any container type without needing further templates
      48                 :             : // or overloads.
      49                 :             : //
      50                 :             : // HOWEVER: This type is possibly slower as the aformentioned wrappers, as it need mores abstraction
      51                 :             : // layers to accomplish the independence of the container type.
      52                 :             : //
      53                 :             : // The type `AnyScan` can only be instantiated/created through `MakeAnyScan` or directly from a
      54                 :             : // compatible `std::initializer_list` argument. Similarly `ConstScan` can be constructed from a
      55                 :             : // `MakeConstScan` call or compatible `std::initializer_list` argument and finally `ConvertingScan`
      56                 :             : // can be constructed from `MakeConvertingScan` or compatible `std::initializer_list` argument. This
      57                 :             : // prevents hard to find issues where the different types and helper functions are incompatible.
      58                 :             : //
      59                 :             : // The implementqtion is type-safe and does not use any `reinterpret_cast` or other unnecessary
      60                 :             : // tricks.
      61                 :             : //
      62                 :             : // The actual `AnyScan` type depends on two types:
      63                 :             : // - `ValueType` which is derived from the container's value-type.
      64                 :             : // - `DifferenceType` which is either `std::ptrdiff_t` or if provided and not compvertible, the
      65                 :             : //   container's `difference_type`. This is done because not all containers that are otherwise
      66                 :             : //   compatible have a `difference_type` but in order for `AnyScan` itself to be compatible with
      67                 :             : //   `std::input_iterator` it has to provide that type. Further, we aim to use a predictable type
      68                 :             : //   as much as possible, so that the callers do not need to unnecessarily guess that type.
      69                 :             : //
      70                 :             : // The more specialized `ConvertingScan` modifies `AnyScan` to accept `MakeConvertingScan` which

      72                 :             : // compatible container. For instance this allows to scan containers of string-like values with a
      73                 :             : // specific string-like container (see below).
