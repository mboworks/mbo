      28                 :             : // mumbo & jumbo -- this library's own hash family and the defaults behind
      29                 :             : // `mbo::hash::GetHash*`: `mumbo` fronts the 64-bit form (plus streaming),
      30                 :             : // `jumbo` fronts the native 128-bit form; both `Algorithm` structs are
      31                 :             : // complete (each delegates the other width), so either plugs in anywhere.
      32                 :             : // The name is MUM + mbo: everything is built on the widening 64x64->128
      33                 :             : // multiply folded to 64 bits (`hash_internal::Mul128Fold64`, the "MUM"
      34                 :             : // mixer) -- one multiply absorbs 16 input bytes and diffuses full-width in
      35                 :             : // both directions.
      36                 :             : //
      37                 :             : // Quality: SMHasher3 PASS 188/188 in BOTH the 64-bit and the native 128-bit
      38                 :             : // form -- the only clean 128-bit result measured on our rig; performance and
      39                 :             : // quality data plus the measured design iterations: see README.md. Values are
      40                 :             : // NOT stable across library versions (library-wide policy) and not
      41                 :             : // cryptographic.
      42                 :             : //
      43                 :             : // Structure:
      44                 :             : // - <= 16 bytes: a fully unrolled `switch` -- every length 0..8 has its own
      45                 :             : //   one-go terminal action (no byte loops), 9..16 use two loads overlapping
      46                 :             : //   the end. The key loads into BOTH operands of the widening product, so the
      47                 :             : //   product is quadratic in the data (a single-operand load correlates
      48                 :             : //   permuted keys pairwise through the shared seed operand).
      49                 :             : // - 17..127 bytes: one sequential MUM chain, 16 bytes per step; the final
      50                 :             : //   <= 16 bytes are read as two loads overlapping the end (no tail loops).
      51                 :             : // - >= 128 bytes: eight independent MUM chains over a 128-byte fetch window,
      52                 :             : //   manually unrolled and interleaved to eliminate execution stalls. Each
      53                 :             : //   starts from a distinct secret so identical stripes cannot cancel on the XOR
      54                 :             : //   merge.
      55                 :             : // - Finalizer: keeps BOTH halves of a widening product and mixes them against
      56                 :             : //   each other, with the length folded into the product operands so it
      57                 :             : //   modulates the result multiplicatively (and only at finalize -- which is
      58                 :             : //   what makes streaming possible).
      59                 :             : // - 128-bit: two lanes with distinct secret banks and swapped operand roles
      60                 :             : //   run over the same input; an interleaved 4-chain bulk tier feeds both lanes
      61                 :             : //   through different nonlinear merges where each lane covers every input byte.
      62                 :             : // - Streaming (64-bit): eagerly consumes full 128-byte blocks, keeps a
      63                 :             : //   rolling window of the last 16 bytes for the overlapping tail reads;
      64                 :             : //   chunked updates produce exactly the one-shot value.
      65                 :             : //
      66                 :             : // The secret constants are nothing-up-my-sleeve numbers: the 64-bit
      67                 :             : // fractional parts of the square roots of the first sixteen primes (the
      68                 :             : // SHA-512 and SHA-384 initial hash values, FIPS 180-4 sections 5.3.5/5.3.4).
