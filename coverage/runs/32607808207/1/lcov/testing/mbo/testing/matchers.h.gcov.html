     361                 :             : // Matcher that allows to compare containers after transforming them. This sometimes allows for much
     362                 :             : // more concise comparisons where a golden expectation is already available that only differs in a
     363                 :             : // simple transformation. The matcher transformation must convert the elements of the container arg
     364                 :             : // from their `value_type` to the matchers value type.
     365                 :             : //
     366                 :             : // That means that a `std::vector` of `int` can be compared to a `std::set` of `std::string`, if the
     367                 :             : // transformer takes `int` as an argument and returns `std::string` as its result.
     368                 :             : //
     369                 :             : // Example:
     370                 :             : // ```
     371                 :             : // std::vector<int> numbers{1, 2, 3};
     372                 :             : // std::set<std::string> strs{"1", "2", "3"};
     373                 :             : // EXPECT_THAT(numbers, WhenTransformedBy([](int v) { return absl::StrCat(v); }, ElementsAre(strs)));
     374                 :             : // ```

     377                 :             : // container's keys, you can transform the input to just return the keys and then compare:
