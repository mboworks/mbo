# StringInterner measurements

[`STRING_INTERNER.md`](STRING_INTERNER.md) reports the retained initial-host measurements for
representative `StringInterner` and `StringInternerMap` configurations. The `data` directory holds
immutable benchmark artifacts, `summaries` holds reproducible derived statistics, and `charts`
holds SVGs generated from those summaries.

The Apple M5 Pro results are provisional. AMD Zen 5 measurements remain a required follow-up and
may change configuration guidance.
